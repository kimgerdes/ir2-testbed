# reproduction/

A copy of the parts of our research repository that `reproduce.ipynb`, `method.py` and `demo.py` need, so that this
folder runs on its own, and the result files behind `results_overview.md`:

- `src/rankrepro/`: the package (data loading, evaluation, the LLM backend, sliding-window listwise re-ranking);
- `scripts/04_run_noveleval.py`: the NovelEval experiment (Table 3 of the paper), run by `reproduce.ipynb`;
- `data/raw/noveleval/`: the 21 NovelEval questions with their 20 judged passages, from the RankGPT repository
  (github.com/sunnweiwei/RankGPT);
- `runs/noveleval/bm25.trec`: the BM25 order of the passages, one of the input orders of the experiment;
- `cache/listwise/rankzephyr_noveleval.jsonl`: the 105 RankZephyr windows of NovelEval, so the notebook needs no GPU;
- `results/testbed_*.json`: `testbed.py score --against ce` for the two MiniLM students of the distillation (Table 7)
  and for the cross-encoder control, on the laptop and, with `_colab`, on the Colab A100;
- `results/replication_summary.md` (and `.json`): the Colab A100 replication against the laptop, run by run and query
  by query; `results/generation_check_scifact_4bit_float16.json`: the same 20 prompts on both GPUs;
- `results/setwise_scifact.json`, `results/setwise_scifact_flant5l_colab.json`: Table 4 with Flan-T5-large, laptop and
  Colab;
- `results/compare_*.md` (and `.json`): the ArguAna depth control, window size and passage length on SciFact (Colab),
  re-ranking depth 50 against 100 on NFCorpus (Colab); `results/truncation.json`: how much of each passage RankZephyr
  read.

Generated by `scripts/pack_submission_reproduction.py` of the research repository; do not edit by hand. Not included:
the distilled students themselves (175 MB), their MS MARCO training data (117 MB), and the per-query results and window
logs behind the comparisons (14 MB). Hugging Face models go to its default cache unless `HF_HOME` is set.
